# 🚗 Uber Ride Data Analysis

An exploratory data analysis (EDA) project on Uber ride data to uncover trends, patterns, and insights about ride usage, peak hours, popular routes, and more.

## 🎯 Objective
Analyze Uber ride data to understand:
- Peak ride times and demand patterns
- Popular pickup/drop-off locations
- Trip duration and distance distributions
- Ride category breakdowns (Business vs Personal)

## 🛠️ Tech Stack
- **Python** — Core language
- **Pandas / NumPy** — Data manipulation
- **Matplotlib / Seaborn** — Data visualization
- **Folium** — Map visualizations
- **Jupyter Notebook** — Analysis environment

## 📈 Analysis Highlights
- 📅 Ride trends by day, week, and month
- 🕐 Peak hours and rush patterns
- 📍 Most popular start/end locations
- 📏 Distance and duration distribution
- 🗂️ Business vs Personal ride comparison

## 🏃 Getting Started
```bash
# Clone the repo
git clone https://github.com/dhanush24-m/UberRideProject.git
cd UberRideProject

# Install dependencies
pip install pandas numpy matplotlib seaborn folium jupyter

# Launch Jupyter Notebook
jupyter notebook
```
